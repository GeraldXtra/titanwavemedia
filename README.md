# Titan Wave Media

The website of Titan Wave Media LTD, an AI company in Lagos, Nigeria.

We build AI for businesses: AI we set up for you, tools you can use today, and data that keeps your customers private.

## What the website does

- Shows what we do: AI setup, our products, synthetic data and privacy.
- Lets visitors try it: a chat assistant demo, a tool that removes personal details from a message, and a sample data maker.
- Answers questions with a site assistant, and hands over to a person on WhatsApp when it is not sure.
- Takes project and quote requests through the contact form.
- Helps people find their way, with a Support page and a site guide that walks through every page.
- Keeps a list of people who want to hear when a product launches.

## Technology

Next.js and React, hosted on Vercel. Supabase for the database, Resend for email, and an AI model for the site assistant.

## Status

The public website is built. Client accounts, the client console and Pay with Titan Wave are built too, and payments run in Paystack test mode until live keys are added.
